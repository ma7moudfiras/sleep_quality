# مميزات البرنامج

**اسم البرنامج:** Sleep Quality Analyzer and Daily Energy Predictor  
**الفكرة العامة:** تطبيق ذكي لتحليل جودة النوم والتنبؤ بطاقة اليوم التالي باستخدام بيانات المستخدم اليومية ونموذج تعلم آلي.

---

## 1. مميزات التسجيل وإدارة البيانات

### 1.1 تسجيل يومي للنوم

يسمح البرنامج للمستخدم بإدخال:

- تاريخ السجل.
- عدد ساعات النوم.
- وقت النوم.
- وقت الاستيقاظ.
- المزاج من 1 إلى 5.
- مستوى النشاط من 1 إلى 5.
- مستوى الطاقة الفعلي لاحقًا: Low / Medium / High.

### 1.2 منع تكرار السجلات

يمنع النظام إنشاء أكثر من سجل لنفس التاريخ، مما يحافظ على نظافة البيانات.

### 1.3 سجل تاريخي كامل

يعرض النظام جميع السجلات السابقة مع:

- بيانات النوم.
- التوقع السابق.
- النتيجة الفعلية.
- أزرار إدخال التغذية الراجعة.

---

## 2. مميزات الذكاء الاصطناعي والتعلم الآلي

### 2.1 توقع الطاقة اليومية

يتنبأ النظام بمستوى الطاقة المتوقع في اليوم التالي:

```text
Low / Medium / High
```

### 2.2 نموذج Random Forest

يعتمد البرنامج على نموذج:

```text
Random Forest Classifier
```

ويستخدم المدخلات التالية:

- sleep_hours
- bedtime_hour
- wake_hour
- mood
- activity_level

### 2.3 التعلم من نتائج المستخدم

بعد أن يحدد المستخدم مستوى الطاقة الفعلي، يستطيع النظام إعادة تدريب النموذج على البيانات الجديدة.

### 2.4 إعادة التدريب

يوفر النظام endpoint وواجهة لإعادة تدريب النموذج:

```http
POST /retrain
```

### 2.5 حالة النموذج

يعرض النظام حالة النموذج مثل:

```text
seed_plus_user_data_2_labeled_rows
```

وهذا يعني أن النموذج بدأ يستخدم بيانات المستخدم إلى جانب البيانات الأولية.

---

## 3. مميزات التنبؤ الذكي

### 3.1 نسبة الثقة

لا يكتفي النظام بإرجاع التوقع، بل يعرض نسبة ثقة مثل:

```text
Prediction: High
Confidence: 96.7%
```

### 3.2 شرح التوقع

يعرض النظام أسبابًا توضيحية مثل:

- Sleep duration is in a strong range.
- Bedtime is within a normal sleep window.
- Mood score supports higher energy prediction.
- Activity level is moderate and not a strong negative signal.

### 3.3 نصيحة شخصية

يرجع النظام نصيحة حسب البيانات المدخلة، مثل:

```text
Your sleep duration looks good. Keep your current routine.
```

---

## 4. مميزات التحليلات

### 4.1 Sleep Consistency Score

يقيس انتظام وقت النوم والاستيقاظ خلال الأيام الأخيرة.

### 4.2 Sleep Debt Calculator

يحسب مقدار نقص النوم مقارنة بالهدف اليومي.

مثال:

```text
Target sleep: 8 hours
Actual sleep: 6.5 hours
Sleep debt: 1.5 hours
```

### 4.3 Weekly Report

يعرض تقريرًا أسبوعيًا يحتوي:

- متوسط ساعات النوم.
- متوسط المزاج.
- متوسط النشاط.
- أكثر مستوى طاقة تكرارًا.
- أفضل وأسوأ أيام النوم.

### 4.4 Habit Streaks

يعرض عدد الأيام المتتالية التي سجل فيها المستخدم بياناته.

### 4.5 Model Personalization Level

يعرض مستوى تخصيص النموذج حسب عدد السجلات المصنفة:

```text
Low / Medium / High
```

---

## 5. مميزات الرسوم البيانية

يعرض البرنامج رسومًا بيانية تساعد المستخدم على فهم سلوكه بمرور الوقت:

- Sleep Trend.
- Energy Trend.
- Mood Trend.
- Activity Trend.

هذه الرسوم تساعد في رؤية العلاقة بين النوم والطاقة والمزاج والنشاط.

---

## 6. ميزة What-if Simulator

تسمح للمستخدم بتجربة سيناريو افتراضي قبل تطبيقه.

مثال:

```text
What if I sleep 8 hours instead of 6?
```

يرجع النظام توقعًا جديدًا بناءً على القيم الافتراضية، مما يساعد المستخدم على اتخاذ قرار أفضل.

---

## 7. مميزات واجهة المستخدم Flutter

### 7.1 تصميم عصري

تم تطوير الواجهة بأسلوب حديث يشمل:

- Material 3.
- Gradient background.
- Cards حديثة.
- Badges للطاقة.
- واجهة Mobile-first.

### 7.2 شاشات المستخدم

البرنامج يحتوي على الشاشات التالية:

| الشاشة | الوظيفة |
|---|---|
| Log | إدخال بيانات النوم |
| History | عرض السجلات والتغذية الراجعة |
| Insights | عرض المؤشرات والتحليلات |
| Charts | عرض الرسوم البيانية |
| Predict | عرض توقع الطاقة |
| What-if | محاكاة سيناريوهات افتراضية |
| System Status | فحص حالة النظام |
| About | معلومات المشروع |

### 7.3 واجهة متجاوبة

تعمل الواجهة على:

- Web browser.
- Android.
- Windows Desktop عند البناء.

## 8. مميزات Backend

### 8.1 REST API واضح

يوفر النظام endpoints منظمة:

```http
POST   /log
GET    /logs
PATCH  /logs/{log_id}/feedback
GET    /predict
GET    /charts
GET    /insights
GET    /weekly-report
POST   /what-if
POST   /retrain
GET    /health
GET    /system-status
GET    /app
```

### 8.2 Swagger UI

واجهة اختبار تقنية متاحة على:

```text
http://127.0.0.1:8010/docs
```

### 8.3 Backend User UI

واجهة استخدام مبسطة داخل Backend على:

```text
http://127.0.0.1:8010/app
```

تفيد في إدخال البيانات واختبار التنبؤ بدون Flutter.

### 8.4 Health and System Status

يوفر النظام فحصًا لحالة:

- الخادم.
- قاعدة البيانات.
- ملف النموذج.
- عدد السجلات.
- جاهزية التنبؤ.

## 9. مميزات جودة البيانات

يعرض البرنامج تنبيهات عند وجود مدخلات قد تكون غير منطقية:

- نوم أقل من الحد الطبيعي.
- نوم زائد جدًا.
- وقت نوم متأخر جدًا.
- محاولة إدخال تاريخ مكرر.

---

## 10. مميزات التجهيز والتسليم

### 10.1 قابل للتشغيل محليًا

يمكن تشغيل النظام كاملًا على جهاز Windows محليًا.

### 10.2 قابل للتحويل إلى ملف تنفيذي

يدعم المشروع تجهيز:

- Flutter Windows EXE.
- Backend EXE عبر PyInstaller.
- ملف تشغيل موحد `Start_Sleep_Quality_App.bat`.

### 10.3 قابل للنشر على الويب

يمكن نشر:

- Flutter Web على Vercel.
- FastAPI Backend على Render.

---

## 11. نقاط قوة المشروع في العرض النهائي

- يجمع بين Flutter وFastAPI وML وSQLite.
- لا يكتفي بالتنبؤ، بل يشرح التوقع.
- يتعلم من النتائج الفعلية للمستخدم.
- يحتوي على تحليلات ورسوم ومؤشرات.
- يحتوي على محاكي What-if داعم للقرار.
- واجهته عصرية وقابلة للتشغيل على أكثر من منصة.

---

## 12. حدود البرنامج

- ليس برنامجًا طبيًا ولا يقدم تشخيصًا صحيًا.
- دقة التوقع تعتمد على كمية وجودة البيانات المدخلة.
- SQLite مناسب للتشغيل المحلي والديمو، أما الإنتاج الحقيقي فيفضل PostgreSQL.
- يحتاج Backend فعالًا حتى تعمل واجهة Flutter بشكل كامل.
